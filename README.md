# Python Calculator
 
A simple calculator application built using Python and Tkinter.
 
## Features
 
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Square calculation (x²)
- History tracking
 
## Technologies Used
 
- Python
- Tkinter
 
## How to Run
 
1. Make sure Python is installed.
2. Run the following command:
 
```bash
python calculator.py
